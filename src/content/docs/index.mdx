This site is the QA team's knowledge base: **what each project is, how we test it, and where the gotchas live** — so that knowledge is not only in people's heads.

**Seeded sections:** MDB / STS, **Federation**, **CPI**, and **CRDC Data Hub** (Submission Portal + Katalon automation). Other projects use the same page template as placeholders. Search is in the site header.

## Run this site locally

```bash
npm install
npm run dev
```

Then open the URL Astro prints (usually `http://localhost:4321`). Edit markdown under `src/content/docs/`.

## Contribute

This repo is public on GitHub. For now, open a pull request against `main` with a page under `src/content/docs/`. A fuller contribution guide is an IDP follow-up (M2). Do not commit credentials, tokens, or private environment URLs.
